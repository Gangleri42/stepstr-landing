Open stepstr

Open any STEP file

stepstr runs in your browser and converts the file on your own device, so nothing is uploaded.

The SeedHammer II from the sh-hardware repository, public domain: 1,076 parts from an 18.2 MB STEP file, drawn by stepstr’s viewer.

Orbit it, zoom right in

Orbit all the way around, zoom out to the whole model, or in until one part fills the screen. Every edge is the STEP file’s own.

Measured on the exact shape

Pick two faces, edges or points, and stepstr measures between them on the file’s exact geometry, not on the triangles on screen.

Switch parts off, or keep one

This list is the file’s own assembly tree. Switch parts off to see what they hide, or keep one alone.

A simple exploded view

One slider moves each part away from the middle of its assembly, level by level, and back again. It is plain and automatic, enough to see what sits inside.

Three cuts at once

Up to three planes, on any axis. Each takes one side away and hatches what it cuts, in the part’s own colour.

The view lives after the #

This address holds the whole view: the file’s sha256, hidden parts, cuts and camera. Browsers never send what follows the # to a server.

stepstr.space/#/u?src=…&x=a6654805…d2af4e72a

Drop a file or paste a link

A file from your disk is read where it lies, and any https link to a STEP file opens if its server allows it.

  • II-v74.step, dropped#/b/a6654805….step?name=II-v74.step
  • raw.githubusercontent.com/…/II-v74.step#/u?src=https%3A%2F%2Fraw.githubusercontent.com…

GitHub pages, zip and gzip

A GitHub page link turns into its raw file, Git LFS included, and zipped or gzipped files are unpacked first.

  • github.com/Gangleri42/sh-hardware/blob/main/…#/u?src=https%3A%2F%2Fraw.githubusercontent.com…
  • model.zip, model.step.gzunpacked on this device

Blossom and Nostr addresses

A Blossom address is the file’s sha256, so any server holding it will do. A Nostr event that points at a STEP file opens too.

  • blossom:sha256:a6654805…d2af4e72a#/b/a6654805…d2af4e72a
  • nevent1… or naddr1…#/n/<pointer>

Inside a Nostr app

The same viewer ships as a napplet, a sandboxed page any Nostr app can host. The app hands it each file; it has no network of its own.
